# Rawmodels Antislop: SBS текстов

Проверен живой API `antislop` на rawmodels.ai. Это отдельная проверка сервиса: API не раскрывает ревизию весов. Отдельная модель `unslop` в доступном списке не найдена.

24 прежних задания: статьи, твиты и блоги, по четыре задания каждого типа на русском и английском. Каждая пара оценена в обоих порядках A/B. Opus 5.5 видит задание, общую рубрику и два ответа, без названий моделей и эталонного текста. GEPA-промпт из `da1013e` адаптирован с pointwise на SBS, как в предыдущем прогоне.

Сервис использует thinking по умолчанию и лимит 8192 токена. Соперники используют ранее полученные ответы без thinking с лимитом 2048 через локальную vLLM/FP8. Везде temperature 1.0, top-p 0.95, top-k 20, seed 271828. Внутренние настройки и ревизия весов сервиса неизвестны. Это сравнение конфигураций сервиса и локальных запусков, а не изолированное влияние весов.

Проба API с `reasoning.enabled=false` не выключила reasoning: все 2048 токенов ушли на мысли, финальный ответ отсутствовал, ошибка `OUTPUT_BUDGET_EXHAUSTED`. Она не входит в SBS. Четыре диагностических ответа переиспользованы из полного прогона; дополнительных запросов нет. Все тексты доступны в `side_by_side.html`.

На 24 успешных задания: 35307 completion-токенов, из них 32914 reasoning и 2393 финального ответа. Сумма вычислена по API receipts; две предварительные неудачные попытки сюда не включены.

После чтения всех ответов: сервис лучше держит объём, чем локальная rft1, но в блогах часто повторяет общие мысли вместо развития аргумента. В твите про Cincinnati финальный ответ содержит рассуждения о подсчёте слов; в твите про колледж начало `up charging` грамматически не стыкуется с `is gonna`. В тексте про Вуш конкретное раздражение заменено фразами о «конструкции» и «благих намерениях». Это качественное чтение с видимыми названиями моделей, а не независимая слепая человеческая разметка. Цитаты и замечания записаны в `manual_notes.json`.
